# Воркфлоу

Оркестрация многоагентной работы над проектом. Каждый файл — скрипт, который
запускается инструментом `Workflow` и раскладывает работу по фазам с явными
гейтами между ними.

Зачем это здесь, а не в голове у агента: **гейт, живущий в пересказе, гейтом не
является.** Блокирующая находка ревью обязана остановить следующую фазу строкой
скрипта, а не абзацем отчёта, — иначе следующая фаза строится поверх сломанного
слоя и чинить придётся оба.

| Файл | Что делает | Когда звать |
|---|---|---|
| `adr-batch.js` | Черновики записей журнала: адвокат → прокурор → судья на каждый вопрос, затем сверка пачки на взаимные противоречия | Когда несколько архитектурных вопросов надо закрыть разом до кода |
| `s0-slice.js` | Реализация тест-сначала: контракт → красный тест → код → независимая проверка → ограниченный цикл починки | Когда есть написанный план и его надо исполнить |
| `conformance-review.js` | Ревью диффа по семи линзам, каждая находка — против трёх скептиков, большинство убивает | После вехи, до принятия работы |
| `doc-sync.js` | Сверка живых документов с кодом; замороженные читаются, но не правятся | После вехи |

## Что они не делают

`adr-batch` **не дописывает** в `docs/DECISIONS.md`. Скилл `/adr` требует
показать текст человеку и дождаться согласия, и это правило старше любого
воркфлоу: журнал — источник истины о том, что уже пробовали отвергнуть, и
запись, попавшая туда без согласования, обесценивает его как источник.

`doc-sync` не правит файлы вовсе — только отчитывается. Правит человек, увидев
весь список сразу: половина расхождений на деле одно расхождение, названное из
двух документов.

Ни один воркфлоу не трогает `docs/SPEC.md`, `docs/NORTH_STAR.md` и
`docs/archive/**`. Первые два заморожены с появлением первого файла в
`crates/liminis-core/src/kernels/` (ADR-032), третий — безусловно. Расхождение с
ними оформляется записью в журнал, а не правкой.

## Как запускать

```
Workflow({ scriptPath: ".claude/workflows/s0-slice.js", args: { waves: [[...]] } })
```

Каждый запуск сохраняет свой скрипт и возвращает `runId`. Правка скрипта и
повторный запуск с `resumeFromRunId` переиспользуют кеш: неизменённый префикс
вызовов возвращается мгновенно, пересчитывается только первый изменённый вызов
и всё после него.

## Цена

Воркфлоу разворачивают десятки агентов и расходуют соответственно. Это
осознанный выбор для задач, где ошибка молчалива: в этом проекте почти каждая
настоящая ошибка молчалива — `floor` вместо округления половин от нуля,
пересчёт наличия после каждой реакции, масштаб от самого обильного участника
вместо самого дефицитного. Ни компилятор, ни линтер, ни один ревьюер их не
видит. Три независимых скептика — видят.
