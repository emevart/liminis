# Liminis

Воксельный симулятор био-экосистемы для изучения существенных эволюционных переходов.

## Прежде чем предлагать архитектурное решение

Прочитай `docs/DECISIONS.md`. Там двадцать четыре ADR, и значительная их часть
фиксирует ровно то, что кажется естественным предложить с чистого листа.

- Если предложение противоречит ADR — **назови номер и скажи прямо**: «это отменяет
  ADR-0NN, потому что …». Не обходи молча, не переизобретай уже отвергнутый вариант.
- **Спека заморожена до первого работающего прогона.** `docs/SPEC.md` и
  `docs/NORTH_STAR.md` не редактируются; PreToolUse-хук это блокирует.
- Новая идея идёт в `docs/OPEN_QUESTIONS.md`, не в SPEC.
- Новое решение — запись **в конец** `docs/DECISIONS.md` через `/adr`, с обязательным
  разделом «Отвергнуто». Существующие записи не правятся: отмена решения оформляется
  новой записью со ссылкой на отменяемую.
- `docs/archive/` — вытесненные черновики. Они противоречат актуальной спеке,
  ссылаться на них нельзя.

## Инварианты

- **Закрытый учёт** (ADR-003). Вещество приходит и уходит только через именованные
  каналы со счётчиками. Инвариант каждого тика: `Δ(поля + клетки) == Σ(потоки по каналам)`.
  Каждый процесс обязан декларировать, сохраняет он массу или через какой канал меняет.
- **Целые массы** (ADR-004). Массы, энергия и объёмы — целые, с per-substance масштабом
  `units_per_kg`. Float допустим только для параметров и производных величин.
- **Потоковые схемы** (ADR-005). Донорно-акцепторный поток через грань: вычли у донора,
  прибавили акцептору. Сохранение точное по построению, а не приближённое.
  Semi-Lagrangian отвергнут. Условие Куранта проверяется при загрузке конфига.
- **Форма ядра под WGSL** (ADR-015). Ядро — функция над плоскими массивами с независимой
  обработкой вокселя, переводимая в WGSL построчно. Внутри запрещены указатели,
  интерфейсы и аллокации в цикле. CPU-версия — вечный эталон, после порта не выбрасывается.
- **Никаких голых операторов над `Q`** (ADR-022). Только обёртки `qmul`, `qdiv`, `qadd`,
  `qsub`, `qexp`, … Трансцендентные функции — таблицами, не библиотечными вызовами.
  Детали и таблица операций — `docs/NUMERIC.md`.
- **Новое вещество добавляется правкой TOML** (ADR-018). Реестры веществ, реакций и
  процессов — по-настоящему данные. Если для нового сценария приходится трогать Rust,
  это дефект архитектуры, а не задача сценария.

## Карта документов

| Файл | Что там |
|---|---|
| `docs/NORTH_STAR.md` | Зачем всё это. Прав он, а не спека, если они расходятся |
| `docs/SPEC.md` | Устройство системы. Заморожена до первого прогона |
| `docs/DECISIONS.md` | Журнал ADR. Append-only |
| `docs/NUMERIC.md` | Типы `M`/`Q`, обёртки, округление, шаблонизация WGSL |
| `docs/COMMUNITY.md` | Аудитории, границы вклада, воспроизводимость как контракт |
| `docs/OPEN_QUESTIONS.md` | Куда идут новые идеи и нерешённые вопросы |
| `docs/PRIOR_ART.md` | Соседние проекты и чем Liminis от них отличается |
| `docs/LEARNING.md` | Что нужно изучить и в каком порядке |
| `docs/archive/` | Вытесненные черновики. Не ссылаться |
| `.claude/rules/kernels.md` | Правила для `crates/liminis-core/src/kernels/**` |

## Команды

```
cargo build --workspace                              сборка
cargo test --workspace                               тесты
cargo clippy --workspace --all-targets -- -D warnings   линт
cargo fmt --all --check                              формат
scripts/test-hooks.sh                                тесты хуков
cargo run -p liminis -- run --config configs/scenarios/hello.toml --seed 42
```

Тулчейн закреплён в `rust-toolchain.toml` и входит в воспроизводимость наравне с
сидом и конфигом (ADR-024).

Правка `configs/**` или `crates/liminis-core/src/kernels/**` без инкремента
`WORLD_FORMAT_VERSION` в `crates/liminis-core/src/version.rs` роняет CI (ADR-020).
