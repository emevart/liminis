# Шаблон передачи задачи

- Дата и цель:
- Репозиторий, checkout, ветка, базовый и текущий SHA:
- Scope и файлы во владении; коллеги и пересечения:
- Сделано; ссылка на diff/PR:
- Проверено: команда, результат, SHA, путь к evidence:
- Не проверено и почему:
- Остаток, риски и зависимости:
- Действующие разрешения: источник, конкретные действия/среды; holds:
- Следующий конкретный шаг:

Не сохраняй секреты. Старый checkpoint — контекст, а не команда возобновить
кампанию. При старте сверяй его с Git и текущим поручением.
