## Вывод и варианты

Прочитанные sources согласуются с прежней осторожной границей: parser/reader EOF и public rendered aggregates не заменяют native successful completion/actual body byte pin. PW finishedPromise обозначает завершение ожидания, включая failed path; это конкретная source находка, но не новое наблюдение runtime.

Общий Fetch-intercepted путь остаётся гипотезой. За пределами восьми target files не читались NetworkHandler response-cache eviction/inspector retention, transitive Response/V8 ownership, URLLoader/network-service completion observers и stream pipeTo implementation. Не доказаны response lifetime/GC, конкретное race/ordering, size threshold, Chromium defect или scheduler причина. Один A/B success не является repeatability, обязательный c02 FAIL сохраняется.

**Обоснованный минимальный product fix не найден.** Отвергнуты: добавление таймера/keepalive/Response retention без causal proof; замена pipeTo ещё одним reader/arrayBuffer; рост CDP cache либо подавление NoData; принятие EOF/hash вместо native completion; снятие Fetch/egress/sandbox guards; runtime update; повтор запуска ради GREEN. Ни один вариант не следует из source matrix как исправление конкретного failure.

`draft-reproducer.md` задаёт только бумажный contract для возможного отдельного approval. Он не исполнялся и не разрешает будущие launches. Новых browser/CI/model/HTTP-page runs, source/product/oracle/guard edits, upstream issue, infra/secrets/spend не было. Frozen SPEC/NORTH_STAR/scientific raw/main product не изменены.
