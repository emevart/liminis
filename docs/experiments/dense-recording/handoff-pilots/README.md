# Измеренные dense pilots

Настоящие100/10k/100k прогоны архивного движка, каждый завершённый tick включая genesis. Полные original chunk/index/manifest bytes сохранены. SHA/размеры каждого файла — в archive-manifest.json. Совпадающие gzip blobs общих префиксов deduplicate в Git. Reports сохраняют source/binary/index hashes, результаты полного декодирования и сравнения архивных контролей, timings и qualified RSS; только command paths нормализованы, raw context не публикуется.

Это evidence-only ветка, не product release/deploy и не приёмка полного1M. Старые public JSON и LAB24/source/SHA не менялись.
