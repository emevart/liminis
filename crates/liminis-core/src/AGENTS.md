# Области liminis-core

Применяются корневые AGENTS.md.

Перед работой с kernels/** прочитай полностью
[численные правила](../../../docs/agent-kernels.md). Они обязательны для ядер;
host/config код не наследует запрет на аллокации внутри ядра как общий запрет.

Для numeric, process, worldgen и config используй соответствующие ADR,
NUMERIC/ARCHITECTURE/CONFIG_SCHEMA и проверки из корневых инструкций.
Инструкции вынесены из kernels/**: CI рассматривает любое изменение внутри
этого каталога как изменение семантики мира. Документы не требуют
искусственного WORLD_FORMAT_VERSION bump и не ослабляют этот guard.
